# WireBender

WireBender is a local Nuxt app for planning hand-soldered perfboards: you draw wires and parts on a hole grid, and it checks the wiring with the same engine in the browser and on the command line. Install with `pnpm install`, start the server with `pnpm dev` (boards are kept in `WIREBENDER_DATA`, default `./.data`), import or create a board from the board list, and check a board file from the terminal with `pnpm check path`. Findings are advisory only.
